# Le Théâtre de l'Emlyon

# Description du projet
Ce projet est une page web réalisée en HTML et CSS représentant un site de théâtre.  
L’objectif est de présenter plusieurs pièces à l’affiche avec un système de cartes cliquables qui ouvrent des popups détaillées.

Le projet met en avant :
- une structure HTML 
- une mise en page avec CSS 
- un système de popup

# Fonctionnalités principales
- Header avec titre + icônes
- Menu de navigation horizontal
- Section "à l’affiche" avec plusieurs pièces
- Popups détaillés pour chaque pièce
- Footer simple

# Technologies utilisées
- HTML
- CSS
- Google Fonts (pour la police Inika)


# Fonctionnement des popups
Les popups fonctionnent  grâce à :
- des liens avec `href="#id"`
- des div avec des `id` correspondants
- la pseudo-classe CSS `:target`

# Utilisation de l'IA
J’ai utilisé l’IA de manière ponctuelle pour m’aider sur certains points techniques.
Exemples :
- Comprendre comment relier une carte à une popup avec les `id`
- Gérer la fermeture d’un popup avec `href="#"` et `:target`
- Positionner des éléments avec `flexbox` et `position: absolute`
- Styliser un lien pour qu’il ressemble à un bouton
